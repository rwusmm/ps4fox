# PS4browser
This is a web browser for PlayStation 4 written in C++17, designed to run on PS4 homebrew and be a functional alternative to the PlayStation 4's built in browser.

Currently it is being in active development, and goal is to get example.com to load perfectly.

Technologies being used:
OpenOrbis
LiteHtml
C++ 17

You can find them by simply doing a quick google search.
